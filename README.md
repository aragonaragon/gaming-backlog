# Gaming Backlog / مكتبة ألعابي

**🔴 التجربة المباشرة:** https://aragonaragon.github.io/gaming-backlog/

موقع/أداة خفيفة لترتيب مكتبة الألعاب الشخصية بدون تسجيل وبدون إيميل. المستخدم يبحث عن اسم اللعبة، يضيفها لمكتبته، ثم يرتب الـ backlog حسب التقييم، مدة اللعب، التصنيف، أو الحالة.

> ملاحظة: نسخة GitHub Pages تستخدم متوسط وقت RAWG (لأن Pages لا تشغّل دوال). للأوقات الدقيقة من HowLongToBeat، انشر نسخة `Netlify/`.

## النسخ الجاهزة

- `Netlify/`  
  نسخة النشر على Netlify. ارفع المجلد كامل أو استخدم ZIP الجاهز.

- `Gaming-Backlog-Netlify.zip`  
  نسخة مضغوطة جاهزة للرفع على Netlify Drop.

- `Download-PC/`  
  نسخة تشغيل محلية على PC.

- `Gaming-Backlog-PC.zip`  
  نسخة PC مضغوطة للمشاركة.

## أهم المميزات

- بحث مباشر عن الألعاب عبر RAWG.
- إضافة اللعبة فوراً للمكتبة.
- حفظ محلي في المتصفح عبر `localStorage`.
- بدون حساب، بدون تسجيل، بدون إيميل.
- صور، تقييم، سنة الإصدار، تصنيفات، Metacritic إن توفر.
- أوقات لعب HowLongToBeat عبر وسيط `/api/hltb`.
- حالات اللعبة: `القائمة`، `ألعبها`، `خلصت`.
- ترتيب حسب التقييم، المدة، تاريخ الإضافة، الاسم، وسنة الإصدار.
- فلترة حسب التصنيف.
- عرض شبكي أو عرض حسب التصنيف الأساسي.
- زر `اقترح لي لعبة` لاختيار لعبة مناسبة من الـ backlog.
- بطاقة `العب التالي`.
- خطة لعب حسب عدد ساعات اللعب الأسبوعية.
- تصدير واستيراد المكتبة كملف JSON.
- وضع demo عبر `?demo=1` لتعبئة ألعاب وهمية للمعاينة.

## تشغيل نسخة Netlify محلياً

من جذر المشروع:

```powershell
python -m http.server 5601 --directory Netlify
```

ثم افتح:

```text
http://localhost:5601/
```

للمعاينة ببيانات وهمية:

```text
http://localhost:5601/?demo=1
```

## نشر نسخة Netlify

الطريقة الأسهل:

1. افتح `https://app.netlify.com/drop`.
2. اسحب مجلد `Netlify` كامل أو ارفع `Gaming-Backlog-Netlify.zip`.
3. بعد النشر، دالة HLTB تعمل عبر المسار:

```text
/api/hltb?name=Elden Ring
```

## تشغيل نسخة PC

افتح:

```text
Download-PC/start-backlog.bat
```

يفتح الموقع على:

```text
http://localhost:5620/
```

للمعاينة ببيانات وهمية:

```text
http://localhost:5620/?demo=1
```

ملاحظة: نسخة PC تحتاج Node.js حتى يعمل وسيط HLTB المحلي. بدون Node.js يمكن فتح `Download-PC/index.html` مباشرة، لكن أوقات HLTB الدقيقة قد لا تعمل.

## مصادر البيانات

- RAWG: البحث، الصور، التقييمات، التصنيفات، وبعض البيانات العامة.
- HowLongToBeat: أوقات القصة / القصة مع الإضافات / 100%.
- التخزين: محلي فقط في `localStorage`.

## ملاحظات تسويقية دقيقة

- الموقع ليس أوفلاين بالكامل من أول استخدام. البحث وإضافة ألعاب جديدة يحتاج إنترنت.
- بعد إضافة الألعاب، المكتبة محفوظة محلياً وتفتح بدون تسجيل.
- `حسب التصنيف` في الواجهة يعني تجميع/عرض حسب التصنيف الأساسي، مع توفر فلترة حسب أي تصنيف.
